# Forma — личный трекер: зал, питание, тело

Android-приложение (Samsung, Android 9+). Без мотивации и лишнего UI — только данные и выводы.

## Установка
GitHub → Releases → последний `Forma 0.1.N` → `forma.apk` → открыть на телефоне → разрешить установку.
Обновления ставятся поверх (ключ подписи постоянный), данные сохраняются.

После установки: вкладка «Настройки» → кнопки разрешений 1–3; при желании — API-ключ Claude.

## Что умеет
- **Сегодня**: план недели (3 будних дня, не 3 подряд, по возможности через день), еда за день, вес.
- **Утреннее уведомление** (по умолчанию 08:00): в день зала — какой день программы и цели по весам/повторам; вчерашние калории/белок; напоминание о взвешивании, замерах, чекапе.
- **Геолокация**: «Адреналин Восток» и Дворец водного спорта; визит ≥ 75 мин засчитывается как тренировка. Точку можно уточнить кнопкой «Я сейчас здесь».
- **Зал**: запись подходов (вес × повторы), цели по двойной прогрессии, e1RM и тренд по каждому упражнению, таймер отдыха.
- **Еда**: пишешь текстом что съел → своя библиотека → Claude с веб-поиском (КБЖУ конкретных заведений Минска) → проверка → сохранение. Повторные блюда — в один тап без ИИ.
- **Сон**: автоматически по телефону (последнее выключение экрана → первая разблокировка утром), среднее, разброс отбоя, напоминание об отбое.
- **Тело**: вес (сглаженный + темп), замеры, % жира по формуле ВМС, фото спереди/сбоку/сзади со сравнением первое↔последнее.
- **Отчёт/чекап** (каждые 14 дней): силовые, объём по мышцам, вес, замеры, питание, конкретные действия; анализ Claude или «Копировать для чата».

## Архитектура (для новых сфер)
- `core/` — чистый Kotlin, покрыт тестами (`./gradlew :core:test`). Всё хранится как универсальные записи `Entry(type, ts, json)` + key-value.
- Новая сфера (готовка, сон…) = новый `Module` в `core` (+ экран в `app/ui`). Утреннее уведомление, чекап и экспорт подхватят её автоматически.
- Программа тренировок — JSON (вкладка «Зал» → «Программа»), меняется без пересборки.
- Методика и правила анализа: `core/src/main/resources/method.md` (она же — системный промпт для Claude).
