# Grind — личный трекер: зал, еда, тело, учёба в БГУИР

Android-приложение (Android 9+, проверялось на Samsung). Без мотивации и лишнего UI — только данные и выводы.
Два раздела с общей палитрой: «Здоровье» (голубой акцент) и «Учёба» (лавандовый).

## Установка
GitHub → Releases → последний `Grind 0.1.N` → `grind.apk` → открыть на телефоне → разрешить установку.
Обновления ставятся поверх, данные сохраняются. На Samsung, если установка блокируется:
Настройки → Безопасность и конфиденциальность → Автоблокировка → выключить на время установки.

После установки: «Настройки» → кнопки разрешений; при желании — API-ключ Claude.

## Что умеет
**Здоровье**
- **Сегодня** — план дня по обоим разделам: что осталось сделать (отмечается само), вода, пары с окнами между ними.
- **Зал** — разделы «План», «Упражнения», «Прогресс», «История»; база упражнений (несколько основных мышц), план по методике
  (вся неделя одним расчётом: каждая мышца хотя бы раз в неделю, два — если успевает восстановиться, не два дня подряд;
  недельный объём на мышцу делится на её тренировки; дни недели дополняют друг друга по вариантам
  движения — вертикальная и горизонтальная тяга, жим и наклонный жим, румынская тяга и сгибания ног; жимы и тяги через раз
  меняются местами; подсказка, каких вариантов не хватает в базе),
  запись каждого подхода или одного итога на упражнение (настройка), упражнения можно убирать и добавлять прямо на тренировке.
  Мышцы и шаг веса угадываются по названию («Французский жим» — трицепс, «Разгибания запястий» — предплечья, гантели —
  через 2 кг); тренировкой мышцы считается только её собственное упражнение (румынская тяга спину не «занимает»).
  «Прогресс» — где сила растёт, а где стоит или падает (по последним 6 неделям): было → стало, график по тренировкам
  (6 недель / 3 месяца / полгода / всё), плановый рост по стажу (до года +1%, 1–3 года +0,5%, 3+ года +0,25% силы
  в неделю) — пунктиром на графике, темп против плана и цель через 4 недели; следующая цель и почему может не идти —
  редко делаешь, мало подходов на мышцу, общий застой (сон, еда, разгрузка), дефицит калорий.
- **Турник** — ежедневные счётчики и тесты, огонёк серии со второго дня подряд (так же — у взвешиваний).
- **Еда** — текстом («макароны с 2 котлетами», «шоколадка 30г», «Lotte Choco Pie банан»): меню KFC, Mak.by, Burger King, Кинзы → своя библиотека и таблица →
  магазины edostavka.by и «Соседи» (товар по названию, КБЖУ с этикетки) → интернет → Claude → проверка → сохранение.
  Рядом с полем — «Авто / Домашняя / Из магазина»: домашнюю еду в магазинах не ищем, покупную ищем там первой.
- **Вода** — норма ≈ 30 мл/кг; нажатие на уведомление «Попей воды» засчитывает стакан.
- **Сон** — автоматически по экрану телефона; время отбоя считается от завтрашней первой пары.
- **Тело** — вес (сглаженный + темп), замеры, % жира.
- **Отчёт** — любой период из календаря, анализ Claude или «Копировать для чата».

**Учёба**
- **Расписание** — лента с сегодняшнего дня (прошлые — по кнопке), ДЗ к парам, фото преподавателей, консультации.
- **Лабы** — задания, «сделана → сдана», лабы и отметки из ИИС, обратный отсчёт до сессии.
- **Кабинет ИИС** — успеваемость, зачётка, пропуски, группа, справки; группа расписания берётся из ИИС.
- **Фоновая проверка ИИС** (≈ раз в 3 часа) — новые отметки, пропуски и лабы приходят уведомлениями.

## Безопасность
- Пароль ИИС не сохраняется: хранится только сессия, зашифрованная ключом Android Keystore.
- API-ключ Claude — тоже в Keystore, не в базе и не в экспорте; в журнал отладки ключи и сессии не попадают.
- Резервное копирование Android выключено: данные не уходят в облако и не восстанавливаются на чужом устройстве.
- Встроенный браузер входа открывает только https://iis.bsuir.by; сессия ИИС уходит только на этот адрес.
- Поиск на edostavka.by идёт из невидимого браузера, открытого только на edostavka.by (сайт пускает лишь браузер):
  картинки не грузятся, другие сайты не открываются, через 3 минуты без дела он закрывается.
- Уведомления об отметках и пропусках скрыты на экране блокировки.

## Архитектура
- `core/` — чистый Kotlin, покрыт тестами (`./gradlew :core:test`). Всё хранится как записи `Entry(type, ts, json)` + key-value.
- `app/` — Compose UI (`ui/`), системные части (`sys/`: уведомления, будильники, фоновые задачи, сейф Keystore), SQLite (`data/`).
- Все напоминания ставятся из одного места — `sys/Reminders.scheduleAll`.
- Методика и правила анализа: `core/src/main/resources/method.md` (она же — системный промпт для Claude).
